# 01 · Pergunta e objetivo

Em D&D 5e, todo monstro tem um **nível de desafio (ND)**: um número que diz o quão perigoso ele é para um grupo de aventureiros. A regra é conhecida pelos mestres, mas eu quis ver nos dados se ela se sustenta.

**Pergunta central:** o ND realmente acompanha o que o monstro tem de "mensurável" (pontos de vida, classe de armadura, XP), e quais monstros fogem do padrão?

**Perguntas menores**
1. Pontos de vida (PV) e classe de armadura (CA) acompanham o ND? Com que força?
2. Quais monstros têm PV muito acima ou muito abaixo do típico do seu ND?
3. Qual tipo de criatura tem ND mais alto (dragão, demônio, fera...)?
4. Monstros com ações lendárias são mesmo mais difíceis?
5. O XP é uma função direta do ND?

**Habilidade que este projeto treina:** pegar dados em JSON (aninhados), transformar em tabela, limpar e explorar com Python (pandas e matplotlib). O projeto anterior (Olist) foi SQL + Power BI.
